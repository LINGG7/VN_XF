# 项目字体管理工具

入口：`Tools > VNovelizer > 字体管理工具`。旧脚本保留原文件与 GUID，旧公开方法转到同一个窗口。

**注意：扫描并生成字符集只更新 TXT，不会自动修改 TMP 字体。新增文字后，还需要在「字库与图集」页点击「增补现有 TMP 字体的缺失字形」。**

## 使用流程

1. 在“字符集”页选择范围并扫描。默认包含剧本（CSV/TSV/XLSX）、C# 脚本、场景和 prefab，跳过 Library、Temp、构建输出、链接目录及 Editor 工具文案。不默认扫描普通 TXT、asset、JSON、XML 等配置，避免收录“7000 汉字”等字体字符库；独立配置/本地化文案可开启“额外扫描配置和普通文本”。支持 Unicode 转义、扩展汉字及 emoji。可通过 TXT 导入或手动补充外部运行时内容预计用字。
2. 选择 TMP 字体及原始 TTF/OTF，检查覆盖率。报告区分主字库、回退字库、可补入图集的字符以及源字体不支持的字符，并列出出现文件。
3. 需要补字时增补原字库，不清空旧字形。完整重建另存为新 `.asset`，可以选择采样字号、留边、图集大小、Static/Dynamic 和多图集。更换源字体必须重建，不能混入旧图集。
4. 在“全项目替换”选择 TMP / Legacy 字体、可选旧字体过滤、prefab/全部场景/配置范围，先预览再应用。支持非激活对象、TMP 3D、UGUI Text、TextMesh、空字体填补和目标材质修复。只读或链接文件会跳过并报告。已打开的未保存场景也会替换字体并支持撤销，但不自动保存其他修改，结果会提醒手动保存；干净场景正常保存。已打开场景按实际对象预览，未打开场景按依赖候选预览。
5. 回退页支持有序回退列表、自身/循环检测，并可单独设置 TMP 全局默认字体。

## 输出与保护

“全项目替换”页的预览与替换按钮固定在窗口底部。先点击“预览全项目替换范围”，有可应用的候选文件后，再点击“备份并替换项目字体”；修改目标字体或替换范围后需要重新预览。

- `output/FontTools/ProjectCharacters.txt`：生成的字符集，稳定排序、无 BOM 的 UTF-8。窗口可直接定位此文件，每次生成前备份旧输出。
- `Assets/TextMesh Pro/Resources/Fonts & Materials/ProjectCharacters.txt`：用户保留的旧字符集，仅供对照；扫描和导出均不修改此文件。
- `output/FontTools/ScanReport.txt`：扫描统计、未处理文件和实际扫描文件清单。
- `output/FontTools/MissingCharacters.csv`：缺字、Unicode 码点和来源文件。
- `output/FontTools/Backups/.../`：每次写入前的原文件及 meta 副本、逐文件替换报告。
- 不删除资源或 meta，不调用清空字体图集、全项目 SaveAssets/Refresh；重建拒绝覆盖已有字体。
- 取消批量替换会停止后续文件，已完成文件及备份保留。报告列出失败和跳过项；不能将有提示的扫描视为覆盖了所有外部/动态内容。

## 边界

TMP 3.0.7 批量补字前会初始化主图集缓存，避免扩展多图集时在 `SetupNewAtlasTexture` 中空引用。若之前补字因此中断，可重新扫描后继续增补；已有字形和图集会保留，无需为此完整重建。源字体不支持的字符仍需配置回退字体。

旧 `.xls`、超大文本和无法解码的二进制文件会提示，需转换或补充字符。代码扫描只收集字符串/字符字面量，支持嵌套插值中的字符串，不再收集注释和中文变量名；仍会收集代码字符串中的日志和属性提示。默认根目录限定为 Assets 和可选的 Packages，跳过 Tests、Samples 及 Editor，不读取项目根目录的临时表格副本。不求值运行时表达式；远程下载文字、用户输入需要动态字库、回退字体或额外字符。UI Toolkit 的文字可额外扫描，但 USS/UXML 内的字体样式链接不属于 TMP/Legacy 资产引用替换范围。保留自定义材质时需自行保证其图集匹配。
