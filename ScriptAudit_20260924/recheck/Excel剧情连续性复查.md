# Excel 剧情连续性复查

范围：2026-09-24 本次读取到的 43 个正式 Excel 工作簿、3570 个剧情节点。Excel 锁文件不计入。仅检查表格，未检查或修改 CSV；未修改任何工作簿。结论基于已保存内容。

## 结论

主要旧问题已修复。仍有三处跨脚本文件名错误、两处多余右括号，以及一处“相信索菲亚”路线的隐藏分支结构缺失。它们不能全部归为硬卡死：文件名错误会加载失败、串线或到表尾；括号错误取决于解析器容错；final(6) 的无匹配分支会直接失去后续。

## 1. sntzm_david313-315(5).xlsx 的三个脚本名仍是中文原名

工作表：圣诺汀之梦_大卫线313-315（终）。

| ID | 单元格 | 当前命令 | 现存目标对应命令 |
|---|---|---|---|
| 2 | K3 | loadScript(大卫线313-315（最终分支）, 2) | loadScript(sntzm_david313-315(6), 2) |
| 50 | K46 | loadScript(大卫线3层（上）, 1) | loadScript(sntzm_david3F(1), 1) |
| 110 | K67 | loadScript(大卫线3层（上）, 1) | loadScript(sntzm_david3F(1), 1) |

这三处所指的中文文件名在当前剧本集合中不存在，现有加载规则不会自动按工作表标题映射文件名。ID 50、110 的出口已补齐，但文件名仍需对应项目的实际名称。

影响：深入探究路线在 ID 2 无法转入 (6)；视为陷阱路线在 ID 50 / 110 无法离开本章，可能串入另一段选项剧情，最终到表尾。

## 2. 两处多余右括号

- sntzm_clark4F(4).xlsx，工作表“圣诺汀之梦_克拉克线4层（终）”，ID 92，K53：
  - 当前：parallel(charfadeout(L,1);charfadeout(R,1))&loadScript(sntzm_final(3), 8))
  - 正确括号形式：parallel(charfadeout(L,1);charfadeout(R,1))&loadScript(sntzm_final(3), 8)
- sntzm_david4F(4).xlsx，工作表“圣诺汀之梦_大卫线4层（终）”，ID 44，K42：
  - 当前：parallel(memoryon();bgfade(sntzm_david313-315(2)_33,1)))
  - 正确括号形式：parallel(memoryon();bgfade(sntzm_david313-315(2)_33,1))

两者都应去掉最后一个右括号。第一处目标 ID 8 实际存在；这里不是缺少 ID 8，而是原命令多出的括号可能进入目标参数或造成解析失败。具体运行表现需要实机验证，不能将静态解析中的“8)”直接当作真实剧情 ID。

## 3. final(6) 补了 ID 103，但缺少引导它的隐藏控制节点

文件：sntzm_final(6).xlsx；工作表：圣诺汀之梦_终局3。

当前结构：

- ID 66：第 53 行，层级 32。
- ID 67：第 54 行，层级 33，顺序继续播放。
- ID 102：不存在。
- ID 100：第 73 行，隐藏控制节点，层级 52。
- ID 86 / 101：第 74 / 76 行，层级 53，只接受“无视飞蛾（克拉克）”“无视飞蛾（大卫）”或“立刻离开”。
- ID 103：第 77 行，层级 34，条件为“相信索菲亚=1”，执行 loadScript(sntzm_final(3), 92)。

因此：仅补 ID 103 还不够。当前没有前置隐藏控制节点去选择它；它也不是 ID 100 的下一层候选。正常“端详飞蛾（克拉克）→相信索菲亚→选择大卫”路线会先顺序走到 ID 100，但不具备 ID 86 / 101 所要求的任何标签，随后停止。

这个后续问题是在审计模型中临时纠正前面的文件名和括号错误后发现的；不是声称当前原表按同一路径已顺利越过所有前置错误。

复现选择示例：开场“不是”→“接听无线电”→“跟上克拉克”→“询问了关于艾米丽的问题”→“开枪故意射偏”→“仔细端详飞蛾”→“优先应对外部威胁，协助队友”→“先发制人，果断逃跑”→“暂且作罢，专注眼前”→“相信索菲亚”→“选择大卫”。

修复方向：在 ID 66 与 67 之间恢复层级 33 的隐藏控制节点 ID 102；让 ID 67 及其后续分支正文到 ID 101 的层级整体增加 1，使 ID 67 与 ID 103 都成为该控制节点的层级 34 候选；ID 103 保持层级 34。这样“相信索菲亚”时选择 ID 103，否则走 ID 67 的无条件分支。应恢复完整层级关系，而不是只额外插入一条空白行。
