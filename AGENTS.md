# Agent Instructions

- Prefer PowerShell 7 (`pwsh`) for all PowerShell commands in this workspace.
- Use Windows PowerShell 5.1 only when a tool or environment explicitly requires it.
- When running commands that may print non-ASCII text, prefer UTF-8 output in `pwsh` to avoid mojibake/encoding issues.
- Keep command output concise and summarize important results for the user.
